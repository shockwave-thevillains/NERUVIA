# H2: halaman 404 bergaya situs (28 Nov 2026)

## 1. Rencana

Satu berkas `404.html` di akar repo yang dipakai Vercel dan GitHub Pages, bergaya landing (monokrom, cyan, Neru), dengan jalan kembali yang jelas, lalu dijaga uji otomatis.

## 2. Keadaan awal

Repo belum punya `404.html`. Pengunjung yang salah alamat mendapat halaman bawaan hosting. Tampilan halaman bawaan Vercel tidak diukur; angka "sebelum" di bagian 5 berasal dari server uji lokal yang menjawab teks polos.

## 3. Rujukan resmi (diakses 28 Nov 2026)

| Sumber | URL | Yang dipakai (parafrase) |
|---|---|---|
| Vercel: Custom 404 pages | https://vercel.com/docs/routing/custom-404-pages | `404.html` di akar keluaran disajikan dengan status 404 untuk alamat statis yang tidak cocok |
| GitHub: Creating a custom 404 page | https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-custom-404-page-for-your-github-pages-site | `404.html` di sumber penerbitan; halaman itu tidak menyebut kode status |

## 4. Keputusan desain

- **Alamat yang diminta tidak ditampilkan.** Teks di alamat bisa dikarang orang lain, jadi memantulkannya membuka pemalsuan pesan. Uji memeriksa 15 alamat, termasuk muatan skrip, karakter pembalik arah, dan alamat sangat panjang.
- **Semua rujukan berawalan `/`.** Halaman ini muncul di alamat sedalam apa pun, sehingga rujukan relatif akan putus.
- **GitHub Pages situs proyek** berada di `/<repo>/`. Skrip kecil menambah awalan itu hanya bila nama host berakhiran `.github.io` dan segmen pertama lolos daftar putih. Host yang hanya mirip tidak diubah. Tanpa JavaScript, rujukan di GitHub Pages situs proyek putus; di Vercel dan domain sendiri tetap benar.
- **Meta CSP di dalam halaman**, karena alamatnya tidak tetap dan GitHub Pages tidak bisa menyetel header. `tools/buat-vercel-json.mjs` mengisinya dan `--cek` gagal bila basi. `frame-ancestors` tidak berlaku lewat meta, jadi tidak ditulis di sana; aturan header untuk `/404.html` tetap ada di `vercel.json`.
- **Tidak ada tautan ke Ruang Belajar.** Folder itu belum ada di `main` (PERLU-KEPUTUSAN).
- Tujuan: beranda, form waitlist (`/#waitlist-d`), dan Kebijakan Privasi. Tidak ada klaim harga, sertifikat, atau penyedia model.
- **Tata letak stabil saat font tertunda.** Ukuran pertama memberi CLS 0,0168 pada 360 px karena paragraf pembuka bertambah satu baris saat font web datang. Perbaikannya: font cadangan bermetrik yang sama dengan beranda, lebar paragraf dalam `em` (satuan `ch` ikut berubah bersama font), dan satu kalimat dipendekkan. Sapuan lebar 320 sampai 860 px (tiap 1 px) dan 868 sampai 1436 px (tiap 8 px) di Chromium lokal tidak menemukan lagi beda tinggi baris antara font cadangan dan font web.

## 6. Uji

`node tools/uji-404.mjs` (727 pemeriksaan): pemeriksa statis; 43 kasus uji mandiri, 40 di antaranya harus ditolak, termasuk `javascript:`, `data:`, alamat berprotokol relatif, jalan keluar akar, dan skrip yang memantulkan alamat; browser pada 390, 768, 1440 px; keyboard; kontrol negatif CSP; tanpa JavaScript; kurangi gerak; peniruan GitHub Pages termasuk segmen jahat dan host mirip. `/404.html` juga masuk `uji-header-csp.mjs`, `uji-gerak.mjs`, dan `ukur-cls-font.mjs`.

| Gerbang | Sebelum perubahan | Sesudah perubahan |

## 7. Tidak diperiksa

- Deploy Vercel dan alamat nyatanya (konektor Vercel dilarang untuk run ini), termasuk apakah header `/404.html` ikut terpasang pada alamat yang tidak ada.
- GitHub Pages nyata; `404.html` baru berlaku di sana setelah Master memindahkannya ke `main`.
- Safari, Firefox, perangkat fisik, dan pembaca layar.
- Pergeseran tata letak dengan font cadangan perangkat nyata (Arial atau Helvetica asli); sapuan memakai font pengganti di Linux.
- Halaman 404 bawaan Vercel tidak diukur.
